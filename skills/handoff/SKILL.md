---
name: handoff
description: 중단·방향 수정·컨텍스트 부족·담당자 변경 때 실제 작업 상태와 다음 행동을 보존한다. 세션 교체나 자동 커밋을 수행하는 스킬은 아니다.
---

요청/AGREEMENT, STATUS, DECISIONS(있으면), git status, 관련 diff·최근 커밋을 확인한다.
docs/HANDOFF.md 또는 지정 인계 위치에 다음을 간결하게 기록한다.
- 목표·범위·현재 단계·기준 커밋
- 완료 근거: 명령·결과·테스트·검증 환경
- 진행 중인 파일·저장 여부·깨진 상태·사용자 변경
- 바로 실행할 다음 행동과 남은 항목
- 정확한 실행·검증 명령, 사용 포트·서버 상태
- 중요한 결정·이유·알려진 문제·제외 범위·반복 실패

검증하지 못한 변경은 그대로 미검증·실패로 기록한다. 인계 때문에 코드나 사용자 변경을 stage/commit하지 않는다.
검증·완료: 기록한 경로·최근 커밋·diff·다음 명령이 실제 상태와 맞는지 읽어 확인한다. 인계 파일 저장과 실제 세션 전환/사용자 수용은 별도이며 현재 세션 유지는 기본이다.
현재 세션을 계속할 수 있다. 압축·교체가 필요하면 문서를 저장한 뒤 적절한 경로를 안내한다.
새 담당자 시작 문장:
“과제 README와 AGENTS.md, docs/HANDOFF.md, docs/STATUS.md를 읽고 git status와 기록된 검증 환경을 확인한 뒤 다음 행동부터 진행해.”

전환 안내는 입력 위치를 나눈다. 현재 Codex 채팅에서는 `/compact`, 실제 과제 루트의 별도 터미널에서는 `codex resume`으로 기존 세션 선택 또는 `codex`로 새 세션 시작이다. 현장 `codex --help`에서 지원을 확인한다. 새 채팅에 위 시작 문장과 수정 금지 파일을 전달한다. 문서 위치가 다르면 실제 경로로 바꾼다. 이전 세션은 같은 파일 편집을 멈추며 상태 자동 공유를 가정하지 않는다. Skill 목록만 갱신되지 않은 경우도 먼저 HANDOFF·Git 상태를 보존하고 재개한다.
