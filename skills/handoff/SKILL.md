---
name: handoff
description: 세션 인계. 다른 사람이나 새 세션이 질문 없이 바로 이어갈 수 있도록 docs/HANDOFF.md를 쓰고, 새 세션에서 입력할 시작 문장을 출력한다. P2 종료, P5 종료, 컨텍스트 부족 시, 제출 직전에 사용.
---

1. docs/STATUS.md, docs/AGREEMENT.md, docs/DECISIONS.md, git log --oneline -20, git status를 확인한다.
2. docs/HANDOFF.md를 최신 상태로 다시 쓴다 (이전 인계는 맨 아래 "인계 이력"에 한 줄로 남긴다).
   ## 목표 (한 줄) 와 합의문 위치
   ## 현재 단계와 시각
   ## 완료된 것 (항목마다 증거: 테스트 이름, 커밋)
   ## 진행 중인 것 (파일, 어디까지 했는지, 깨진 상태인지)
   ## 다음 할 일 (순서대로 3~5개, 1번은 바로 실행할 수 있는 구체적 지시)
   ## 실행과 테스트 방법 (명령 그대로)
   ## 주요 결정과 이유 (DECISIONS 요약 3줄)
   ## 알려진 문제와 함정 (포트, 환경, 잘 깨지는 곳)
   ## 하지 말 것 (합의에서 제외한 것, 이미 실패한 접근)
3. 저장되지 않은 변경이 있으면 커밋하고 "[P단계] handoff 작성"으로 커밋한다.
4. 마지막에 새 세션 시작 문장을 그대로 출력한다:
   "AGENTS.md, docs/HANDOFF.md, docs/STATUS.md를 읽고 이해한 내용을 3줄로 요약한 뒤, 다음 할 일 1번부터 진행해."
