description: 새 과제의 P1 또는 모호한 요구에서 README·제출·데이터 근거를 조사하고 사실과 가정을 분리한다. 명확한 단순 수정에는 생략한다.
---

README·과제 안내·제출 형식·git status와 관련 진입점부터 읽는다. 전체 저장소를 반복 탐색하지 않는다.
확인된 사실 / 미검증 가정 / 제안된 해법을 분리한다.

업무·성공 기준이 불분명할 때만 질문한다. 최근 사례 → 현재 처리 → 비용·빈도 → 사용자·유지 주체 → 제약 중 결과를 바꾸는 질문을 고른다.
정해진 질문 수나 인터뷰를 강제하지 않는다. 답변·수치가 없으면 미확인으로 남긴다.
버그 수정이면 인터뷰 대신 재현 입력·기대 결과·실제 결과·관련 테스트를 확보한다.
데이터는 어디서 오는지, 안 풀면 무엇이 비싼지, 누가 유지하는지 확인한다.
실무자 질문은 사용자가 전달할 짧은 초안으로 제공한다. `notes/STAKEHOLDER.md` 같은 플랫폼 내부 메모에서 실제 수신 답변을 읽고 출처·미응답을 구분한다. 외부로 직접 보내지 않는다.

큰 작업이면 docs/DISCOVERY.md 또는 과제 지정 문서에 근거와 가장 중요한 문제 하나, 선택지를 짧게 기록한다.
다음 실행 가능한 행동을 제안한다. 명확한 요청과 기존 권한이 있으면 별도 합의 의식을 기다리지 않는다.
검증·완료: 필수 기능·제출 형식·데이터 출처·제약·실제 마감 근거와 미확인 질문을 구분했으면 P2로 계속한다. 실무자 응답을 기다리는 독립 구현은 막지 않는다.
