---

사용자 요청·README·발굴 근거로 docs/AGREEMENT.md 또는 지정 문서를 작성한다.
문제 / 필수 범위 / 제외 / 제약·가정 / 수용 기준과 검증 위치 / 위험을 적는다.
기준은 관찰 가능해야 한다. 숫자가 적합하지 않으면 예시 입력과 기대 동작으로 정한다.
현재 수치·실무자 확인·비용 절감은 근거가 있을 때만 기록한다. 모르면 미측정·미확인이다.

결과에 영향을 주는 모호함만 사용자에게 확인한다. 기존 요청이 명확하고 설계가 위임됐으면 근거를 적고 진행한다.
실무자에게 보낼 초안이 필요하면 작성하되 직접 전송하지 않는다. 실제 확인 전 확인됨으로 적지 않는다.
기존 AGENTS.md에 합의문을 복사하거나 수정하지 않는다.
STATUS에 현재 범위와 다음 slice를 기록한다. 리뷰·인계·세션 교체는 필요할 때만 선택한다.
