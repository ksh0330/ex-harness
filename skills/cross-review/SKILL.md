이 세션은 검토 전용이다. 파일을 수정하거나 커밋하지 않는다.

# 대상이 합의문일 때 (docs/AGREEMENT.md)
- 성공 기준이 숫자, 현재값, 측정 위치를 갖췄는가
- 범위가 180분 안에 가능한가, 핵심 간극 하나에 집중했는가
- 모호한 표현, 빠진 제약, 실무자 발언(docs/DISCOVERY.md)과 어긋나는 부분

# 대상이 코드일 때
- 요구사항 충족: AGREEMENT의 P0와 성공 기준이 코드와 테스트로 확인되는가
- 기능 정확성: 실제 실행 경로의 버그, 예외 처리, 경계값
- 보안: 비밀값, 입력 검증, 인젝션, 권한, 개인정보
- 유지보수성: 구조, 중복, 이름, 다음 사람이 이해할 수 있는가
- 문서와 코드 불일치: README, docs의 주장이 실제 코드와 커밋에 있는가

# 출력
심각도 순 상위 5개:
| 심각도 | 위치 (파일:줄) | 문제 | 왜 위험한가 | 제안 |
마지막에 "그대로 제출해도 되는가: 예/아니오와 이유 한 줄".
