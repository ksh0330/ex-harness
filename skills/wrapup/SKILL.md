name: wrapup
description: P7 제출 의식. 필수 제출물, 새로 실행한 검증, 문서와 코드 일치, 최종 인계를 점검하고, 후속 서술형 대비 요약을 화면에 보여준다. 기능 동결 직후 사용.
---

1. 과제가 요구한 필수 파일이 정확한 경로와 이름으로 있는지 확인한다.
2. README에 적힌 실행 명령과 테스트 명령을 그대로 새로 실행하고 결과를 보여준다.
3. 문서 정리 (과제 지정 문서가 있으면 그 양식 우선):
   - README: 실행 방법, 구현 범위, 성공 기준 대비 결과(증거 위치), 주요 결정, 알려진 한계와 다음 계획
   - 문서에 적은 모든 주장이 실제 코드나 커밋으로 연결되는지 대조한다.
4. 디버그 출력, 임시 파일, 비밀값을 제거한다.
5. handoff 스킬 절차로 최종 docs/HANDOFF.md를 쓰고 "[P7] 제출 준비 완료"로 커밋한다.
6. 파일로 저장하지 말고 화면에만 서술형 대비 요약을 보여준다:
   - 구조: 핵심 파일 5개와 역할 한 줄씩, 요청이 처리되는 흐름
   - 결정 3개: 무엇을, 왜, 버린 대안
   - 약점 5개를 이 형식으로: 약점 지점(파일:함수) > 왜 위험한가와 파급 > 다음에 무엇을 검증하고 개선할지
   - 장애 시나리오 2개: 무엇이 깨지면 어떤 증상이 나고 어떻게 대응하는가
