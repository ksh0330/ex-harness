---

과제 지정 경로·파일·형식을 우선 확인한다. 새 기능보다 필수 수용 기준의 남은 결함을 처리한다.
README의 핵심 실행과 검증 명령을 새로 확인한다. 계속 실행할 서버는 사용자에게 명령을 안내하고 미확인 UI를 표시한다.
문서 주장을 실제 코드·테스트와 대조한다. 사용자 파일을 임시 파일로 오인해 삭제하지 않는다.
필수 검증 실패를 숨기거나 “준비 완료” 커밋을 만들지 않는다.
허용된 경우 검증된 이번 파일만 커밋한다. 시험에서는 push하지 않는다.
큰 작업은 최종 HANDOFF와 STATUS에 기준 커밋·검증·미완료·다음 행동을 남긴다.
구조와 데이터 흐름, 중요한 결정과 버린 대안, 실제 약점·영향·개선 방법을 설명한다.
설명이나 후속 질문의 전제가 실제 구현과 다르면 차이를 먼저 밝힌다. 추정·대체값·Mock을 실제 결과로 설명하지 않는다.
사용자의 직접 실습·수용·Cofa 확인이 남아 있으면 별도 표시한다. 서술형 제한이 시작되면 AI 사용을 안내하지 않는다.
